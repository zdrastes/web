# Аналитика L2 — демо-версия

Дашборд «Обращения L2»: динамика обращений по продуктам и причинам, настройки групп
и меток, спринты, управление проектами и пользователями.

## Возможности

- Динамика обращений: по неделям, по продуктам, по группам причин.
- Причины обращений: расшифровка меток трекера, скрытые и служебные метки.
- Настройки: группы причин, спринты, проекты, пользователи и права.
- Импорт/экспорт: перенос настроек между контурами.

## Демо-режим

Проект поставляется с демо-режимом: без трекера и SSO, на синтетических данных.

```bash
pip install -r requirements.txt
copy .env.example .env
python -m uvicorn app.main:app
```

Откройте http://127.0.0.1:8000 — вход в демо-режим происходит автоматически.

## Запуск тестов

```bash
pip install -r requirements-dev.txt
python -m pytest
```

## Конфигурация

Все настройки — через переменные окружения (`.env`). Полный список — в `.env.example`.
Демо-режим включается `DEMO_MODE=1` и не требует трекера и SSO.
