Как читать проценты

«%» — доля обращений группы от суммы обращений всех групп за ту же неделю; у причины — её доля внутри своей группы. Данные — трекер задач, обращения считаются по неделе создания задачи. Изменение процента показано в процентных пунктах (п.п.). Изменение количества в % считается отдельно. Прочерк означает отсутствие данных; на графике линия на этом месте прерывается.

Настройки

Проекты синхронизируются с трекером: укажите namespace и код проекта — по ним подтягиваются задачи и метки.

Обращение попадает в первую (по порядку) группу среди его меток; «причина» — первая метка этой группы. Порядок групп задаётся стрелками.

Нераспределённые метки

Обращения считаются по датам спринтов: день обращения (по МСК) попадает в спринт, в чей диапазон он входит. Границы включительно, диапазоны не должны пересекаться.

Расшифровка метки показывается на дашборде вместо её имени (например, «ls_trs_12» → «Проблемы с заявками 12 типа (спецзаявки)»). Пустое поле — показывать имя метки как есть. Свободную метку (не входящую ни в одну группу) можно удалить — вернуть её можно в блоке «Удалённые метки» ниже. Метки у каждого проекта свои — переключайте проекты вкладками выше.

Роль задаёт стартовый набор функций, чекбоксы — точную настройку для каждого пользователя. Свою роль и функции изменить нельзя.
